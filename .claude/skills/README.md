# Brand & Marketing Skills

29 skills from `arnabbagxd/brand-building-skills`, installed via `npx skills add`.

## How to use them

- **Just describe the task.** Skills trigger on natural phrasing — "I need a name
  for this," "our about page sounds generic," "why aren't my ads converting."
- **Or type `/`** to see the full menu; `/brand` filters to the brand ones.
- **Or name one directly:** `/brand-naming`, `/meta-ads`, and so on.

Start with `/brand-context` once. It writes a brand profile that every other
skill reads first, so you stop re-answering the same setup questions.

## Where they work

These live in the repo, so they load in any Claude Code session opened on this
project — not in sessions on other projects. To get them everywhere, install the
same pack into `~/.claude/skills/`.

Skill files are in `.agents/skills/`; this directory holds symlinks to them.
`skills-lock.json` at the repo root pins each skill's source and content hash.
